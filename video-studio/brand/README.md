# Бренд-кит «Суть за минуту»

Готовые картинки для YouTube и Instagram в стиле роликов: ночной фон (тема `midnight`),
жёлто-оранжевый акцент и шрифт Montserrat, как в заголовках роликов.

**Знак канала** — толстое жёлтое кольцо, открытое справа. Это одновременно буква «С» и
секундомер (сверху кнопка), внутри белая искра, она же «суть». Знак читается даже в кружке
24 px: проверочный лист — `avatar-preview.png`.

Название, слоган, рубрики и время выхода берутся из `channel.json`. Поменяли там —
перерисуйте картинки (см. «Как перерисовать» внизу).

## Что куда загружать

| Файл | Размер | Куда |
|---|---|---|
| `avatar-youtube.png` | 800×800 | YouTube → фото профиля |
| `banner-youtube.png` | 2560×1440 | YouTube → баннер |
| `watermark-youtube.png` | 150×150, прозрачный фон | YouTube → водяной знак |
| `avatar-instagram.png` | 1080×1080 | Instagram → фото профиля |
| `highlights/*.png` (8 шт.) | 1080×1920 | Instagram → обложки «Актуального» |
| `instagram-post-intro.png` | 1080×1350 (4:5) | Instagram → первый пост-знакомство |
| `banner-safe-preview.png` | 2560×1440 | **не загружать**: проверка, что видно на каком экране |
| `avatar-preview.png` | 1600×760 | **не загружать**: аватар и водяной знак в реальных размерах |

## YouTube (с компьютера, studio.youtube.com)

1. **Фото профиля и баннер.** YouTube Studio → слева **«Настройка канала»** → вкладка
   **«Профиль»** (в старом интерфейсе — «Брендинг»).
   - «Фото профиля» → **«Изменить»** → `avatar-youtube.png`. Рамку не двигайте: знак уже по центру
     круга. Лимит YouTube — 4 МБ, наш файл около 0,15 МБ.
   - «Изображение баннера» → **«Изменить»** → `banner-youtube.png`. В окне кадрирования
     ничего не трогайте и нажмите **«Готово»**. Весь текст стоит в зоне 1546×423, которую видно
     на всех устройствах; иконки рубрик по бокам видно только на компьютере и ТВ. Лимит — 6 МБ,
     у нас около 1,2 МБ.
2. **Водяной знак.** Там же, блок **«Водяной знак»** (ищите в «Профиле» или во вкладке
   «Брендинг») → **«Загрузить»** → `watermark-youtube.png` → «Время показа»: **«Всё видео»** →
   **«Опубликовать»**. Когда зритель наводит курсор на знак, YouTube сам показывает кнопку
   «Подписаться». Лимит — 1 МБ, у нас 17 КБ.
3. Нажмите **«Опубликовать»** справа вверху. Баннер и аватар обновляются в течение нескольких
   минут, иногда до суток.

С телефона: приложение YouTube → «Вы» → ваш канал → карандаш («Изменить») → значок камеры
на баннере или на аватаре. Водяной знак ставится только через компьютерную Studio.

## Instagram (с телефона)

Перекиньте файлы на телефон **без сжатия**: например, в Telegram «Избранное» отправьте их
**как файл**, а не как фото, и сохраните в галерею.

1. **Фото профиля:** Профиль → **«Редактировать профиль»** → **«Изменить фото»** →
   «Выбрать из галереи» → `avatar-instagram.png`.
2. **Обложки «Актуального»** (по одной на рубрику). Instagram вырезает из центра круг; всё
   важное уже внутри него.
   - Создать: выложите в сторис хотя бы одну историю этой рубрики (подойдёт сама обложка или
     репост Reels). Затем Профиль → **«+ Новое»** под описанием → выберите истории → **«Далее»**
     → **«Редактировать обложку»** → значок галереи → файл из `highlights/` → **«Готово»**.
   - Поменять обложку: долгий тап по кружку → **«Редактировать актуальное»** →
     **«Редактировать обложку»**.
   - Названия под кружками (видно примерно 10–15 символов):

     | Файл | Название |
     |---|---|
     | `mind.png` | Мозг |
     | `body.png` | Тело |
     | `space.png` | Космос |
     | `nature.png` | Природа |
     | `history.png` | История |
     | `tech.png` | Техно |
     | `money.png` | Деньги |
     | `why.png` | Почему? |

3. **Пост-знакомство:** «+» → **«Публикация»** → `instagram-post-intro.png` → формат **4:5**
   (значок кадрирования, чтобы картинку не обрезало в квадрат) → текст → «Поделиться». Потом
   «⋯» на посте → **«Закрепить в профиле»**. В сетке профиля пост показывается в 3:4, поэтому
   поля по бокам оставлены с запасом.
   Пример подписи:
   > Привет! Это «Суть за минуту»: сложное — просто, каждый день. Два коротких ролика в 12:00
   > и 19:00 МСК: мозг, тело, космос, природа, история, технологии, деньги и повседневные
   > «почему». Только проверяемые факты. Подпишись — каждый день новая суть за минуту.
   > #сутьзаминуту #факты #наука #интересно #познавательно #научпоп #знаешьли

Эту же картинку можно выложить на YouTube во вкладку «Записи» как первое сообщение канала.

## Как перерисовать

```bash
npm run brand                                   # всё → brand/ (≈30 с)
npm run brand -- --only=avatar,banner           # только часть: avatar, banner, watermark, highlights, post, preview
npm run brand -- --out=out/brand-test           # в другую папку, brand/ не трогать
npm run brand -- --raw                          # без сжатия PNG (файлы в 3–6 раз тяжелее)
npm run studio                                  # посмотреть и подвигать вживую: папка «Brand»
```

- Тексты, рубрики и время выхода правятся в `channel.json`, после правки снова
  `npm run brand`. Короткие подписи для обложек «Актуального» лежат в
  `src/remotion/brand/data.ts` (`SHORT`). Для новой рубрики без подписи берётся первое слово
  её названия, а иконка — по имени из [lucide.dev](https://lucide.dev/icons) (поле `icon`).
- Дизайн лежит в `src/remotion/brand/`: знак в `BrandMark.tsx`, остальное в файлах с
  говорящими именами.
- PNG по умолчанию сжимаются до палитры из 256 цветов с дизерингом. На глаз разницы нет,
  весь кит весит около 5 МБ вместо 24. Сжимает ffmpeg, который идёт в комплекте с Remotion,
  так что на Windows ничего ставить не нужно.
- Первый запуск на новом компьютере сам скачивает браузер для рендера (~100 МБ, один раз).
