# Фоновая музыка

Сюда кладутся треки для фона роликов. Конвейер сам выбирает подходящий трек,
копирует его в папку рендера и, если нужно, добавляет атрибуцию в описание
ролика на YouTube.

Сами треки в проекте не лежат: у каждого своя лицензия, и выбирать их вам.

## Как выбирается музыка

Переменная `MUSIC` в `.env`:

| Значение | Что происходит |
|---|---|
| `auto` (по умолчанию) | трек из этой папки (или из `MUSIC_DIR`). Если папка пуста, звучит сгенерированный эмбиент |
| `generated` | спокойный эмбиент-пэд, синтезированный локально под длину ролика. Лицензий и Content ID нет: музыка ваша |
| `none` | без музыки |
| путь к файлу | этот трек, например `MUSIC=music/my-track.mp3` |
| путь к папке | трек из указанной папки |

Поддерживаются форматы `.mp3`, `.wav`, `.m4a` и `.ogg`.

Из подходящих треков выбор делается по «зерну» ролика. Один и тот же ролик
всегда получает один и тот же трек, а разные ролики получают разные. Если у
сценария задано настроение, предпочтение отдаётся трекам с этим настроением.

## Где брать бесплатную музыку для YouTube

1. **Фонотека YouTube** (YouTube Audio Library). Откройте
   [studio.youtube.com](https://studio.youtube.com), затем «Фонотека».
   - Это самый безопасный вариант: треки разрешены для монетизируемых роликов,
     и Content ID их не трогает.
   - Обратите внимание на колонку «Лицензия». Треки с пометкой «Требуется
     указание автора» можно использовать, но строку атрибуции нужно скопировать
     в поле `attribution` (см. ниже). Тогда она сама попадёт в описание ролика.
2. **Pixabay Music** ([pixabay.com/music](https://pixabay.com/music/)).
   - Лицензия Pixabay Content License: можно в коммерческих роликах, указывать
     автора не обязательно.
   - Часть треков зарегистрирована в Content ID. Если YouTube выставит
     претензию, её снимают сертификатом лицензии со страницы трека. Безопаснее
     брать треки без отметки о Content ID.
3. **Incompetech** (Kevin MacLeod, [incompetech.com](https://incompetech.com)).
   Лицензия CC BY 4.0: автора указывать обязательно, через поле `attribution`.

Не берите треки с лицензией «NC» (некоммерческая) и музыку с Jamendo без
платной лицензии, если канал монетизирован. Под голос лучше подходят
инструментальные треки без вокала.

> Если ролики рендерятся в GitHub Actions, треки должны лежать в репозитории.
> Держите такой репозиторий **приватным**: лицензии фонотек разрешают
> использовать музыку в ваших роликах, но не выкладывать сами файлы в открытый
> доступ.

## Описание трека (json-файл рядом с ним)

Рядом с треком положите json-файл с тем же именем: `calm-waves.mp3` →
`calm-waves.json` (подойдёт и `calm-waves.mp3.json`). Все поля необязательны.

```json
{
  "title": "Calm Waves",
  "artist": "Somebody",
  "license": "YouTube Audio Library",
  "attribution": "Music: Calm Waves by Somebody, https://example.com (CC BY 4.0)",
  "moods": ["calm", "ambient"],
  "sourceUrl": "https://example.com/track"
}
```

- `attribution`: готовая строка для описания ролика. Если её нет, строка
  собирается из `title`, `artist` и `license`. Если нет и json-файла, ролик
  выходит без атрибуции.
- `moods`: настроения трека. Распознаются `calm`, `inspiring`, `upbeat`, `tech`
  и `dark`, а также синонимы по-английски и по-русски: «спокойный»,
  «вдохновляющий», «бодрый», «научный», «космос», «драматичный», «тревожный»,
  «эпичный» и т. п.

## Громкость

Голос в конвейере выравнивается до RMS около −18 dBFS. Сгенерированный
эмбиент мастерится тихо: около −17 LUFS, пик не выше −2 dBFS. Треки из
фонотек обычно громче (−9…−14 LUFS). Итоговую громкость музыки под голосом
задаёт композиция (`music.volume` и приглушение на время речи), поэтому
заранее менять громкость файлов не нужно.
