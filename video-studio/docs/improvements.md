# Что улучшить дальше — разбор от 10.10.2026

Разбор сделан по коду, 22 готовым сценариям (01a–11b), `content/videos.json` и `usage.jsonl`.

Что видно по готовым роликам:
- **Длина** — от 48,8 до 67,5 с, медиана около 57 с; 5 роликов длиннее минуты. Цель в коде — 45 с
  (`script/generate.ts`), в `fact-check.md` обещано ≈ 43–48 с.
- **Одинаковый шаблон** у всех: 8–9 сцен, хук, ровно одна сцена `media` (у 20 из 22), в конце `cta`.
- **Одинаковый финал** у всех 22: «напиши в комментариях и подпишись».

Пометка «гипотеза» — эффект ожидаемый, проверить по данным удержания (п. 2).

## Топ-10 по пользе

1. **Стоковое видео Pexels и Pixabay — S, нужен владелец.**
   - Что сейчас: в описаниях 01a–09b нет блока «Видео и фото». У 10a–11b все кадры из Wikimedia и
     часто мимо темы (гравюра 1720 года на запрос «old book candle desk»). Похоже, в секретах
     GitHub нет `PEXELS_API_KEY` / `PIXABAY_API_KEY`.
   - Владельцу: завести бесплатные ключи и добавить в Secrets.
   - В коде: добавить их в `SECRET_NEEDS` (`panel/lib/state.ts`) и в `video-studio-check.yml`,
     чтобы панель напоминала о них.
2. **Удержание из YouTube Analytics API — M, нужен владелец.**
   - Что сейчас: в `YT_SCOPES` нет `yt-analytics.readonly`, поэтому панель видит только просмотры,
     лайки и комментарии.
   - В коде: по каждому ролику брать средний процент и длительность просмотра и кривую удержания;
     порог монетизации считать по засчитанным просмотрам.
   - Аудит для чтения аналитики не нужен.
   - Владельцу: включить Analytics API, заново пройти `npm run youtube-auth` и обновить
     `YT_REFRESH_TOKEN`.
   - Без этих данных остальные правки — вслепую.
3. **Темп: убрать ≈ 6 с тишины — S.**
   - Между сценами набегает ≈ 0,57 с: хвост голоса 180 мс (`voice/provider.ts`),
     `SCENE_TAIL_FRAMES` 14 + `SCENE_LEAD_FRAMES` 8 − переход 12, плюс лишняя секунда у последней
     сцены (`src/types.ts`).
   - Для Shorts: LEAD 8→3, хвост финала 30→10 кадров.
   - Откалибровать `WORDS_PER_SECOND` (2,6) по реальным `props.json` или снизить цель до ≈ 38–40 с.
   - Ужать допуск длины текста с 0,75–1,3× до ±10 %.
   - Эффект: минус 8–12 с и выше процент досмотра (гипотеза).
4. **Финал-петля вместо призыва на 6–8 с — S–M.**
   - Что сейчас: призыв до 18 слов, лишняя секунда и анимация курсора с колокольчиком
     (`CtaScene.tsx`) — на этом месте зритель листает дальше.
   - Призыв: не длиннее 8 слов, только вопрос по теме.
   - «Подпишись» — плашкой на экране без голоса.
   - Последняя фраза подводит обратно к хуку.
   - В `validate.ts`: предупреждать, если финал повторяет прошлые сценарии.
5. **Живой первый кадр — S, гипотеза.**
   - Что сейчас: хук под сильным затемнением (тонировка 0,5 + градиент до 0,85, `MediaLayer.tsx`),
     первый кадр почти всегда тёмный фон с текстом.
   - Если видео нашлось — `dim="soft"`; блик заставки (`BrandSting.tsx`) оставить только на плашке.
6. **Больше сцен с видео — M.**
   - В `prompt.ts` для Shorts требовать 2–3 сцены `media`.
   - В `StatementScene`/`StatScene` при видео-фоне — `dim="soft"`.
7. **Аудит YouTube API — S + ожидание, нужен владелец.**
   - Текст заявки готов: `docs/youtube-audit.md`.
   - Владельцу: ссылки на privacy/terms в Branding, запись экрана и решение по общему проекту
     Google.
   - После аудита автопилот сам загружает ролики на YouTube, ручная загрузка с телефона уходит.
8. **Кросспостинг в Telegram и VK — M.**
   - Telegram: Bot API, `sendVideo` до 50 МБ (шорт весит ≈ 20 МБ).
   - VK: официальный API видео; доступность клипов через API нужно уточнить.
   - В коде: шаг после рендера, включение флагом в `channel.json`.
9. **Не тратить квоту озвучки и не выпускать ролики «не тем» голосом — S–M.**
   - 10a и 10b озвучены дважды: при пересборке теряется кэш `*.voice.json`. Кэшировать по хэшу
     текста, голоса и стиля.
   - Когда квота Gemini кончается, ролик молча озвучивается Edge. Для автопилота ставить
     `TTS_FALLBACK=none` — повтор соберёт ролик назавтра.
   - В карточке ролика показывать, каким голосом он озвучен.
10. **Первый комментарий с источниками и вопросом — S–M.**
    - После «Найти новые загрузки» — `commentThreads.insert` (50 единиц квоты).
    - Закрепить комментарий можно одним нажатием в приложении.
    - Нужно право `youtube.force-ssl` — выдать при переавторизации из п. 2.

## Ещё по роликам

- **10b — тест слепого пятна не сработает.**
  - Что сейчас: крестик и точка стоят на экране телефона в ≈ 1 см друг от друга, а нужно 5–7 см
    и пауза 4–5 с.
  - Нужна раскладка «тест»: крестик у одного края, точка у другого, без фона и субтитров.
  - Если 10b ещё не загружен — пересобрать.
- **Музыка:** папка `music/` пуста, всегда звучит синтезированный эмбиент. Положить 10–20 треков
  из Фонотеки YouTube; в коде — настроение музыки по рубрике.
- **Субтитры** — 70 px, жирность 800, 2 строки, активное слово жёлтым: в порядке, не трогать.

## Рост канала

- **Рубрики по данным:** `pickPillars` (`src/cli/plan-extend.ts`) всегда берёт самые редкие рубрики.
  После 30–40 роликов взвешивать по удержанию и просмотрам.
- **Заголовки** до ≈ 50 символов, дополняющие хук, а не повторяющие его (гипотеза).
- **Викторина** — каждым 3–4-м роликом; «Часть 2» — для выстреливших.
- **Деньги:** реклама YouTube в России отключена с 2022 года. Проверить в Studio, доступна ли
  партнёрская программа для страны канала. Главный рычаг — ролики на других языках (идея 14,
  основа уже есть).
- **TikTok:** только витрина и статистика (`tiktok-setup.md`). Creator Rewards в KG/KZ/RU нет, ролики
  нужны длиннее минуты.
