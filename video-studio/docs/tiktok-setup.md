# TikTok: статистика в панели

Панель показывает статистику TikTok на странице «TikTok» (ссылка вверху «Статистики»):
- подписчики, лайки профиля, ролики;
- просмотры за 30 дней, среднее на ролик, вовлечённость;
- график и список роликов с просмотрами, лайками, комментариями и репостами.

Ролик получает код темы (08a…), если в его подписи есть название из плана. Панель только читает
данные: ничего не публикует и не меняет.

## Что важно знать заранее

- **Автопубликации через API не будет.** К публикации TikTok пускает только приложения, прошедшие
  проверку, и прямо отказывает тем, что сделаны для своего аккаунта. Цитата из правил: «Apps must
  not be for private or personal use… Not acceptable: a utility tool to help upload contents to the
  account(s) you or your team manages». Без проверки ролик через API выходит только с доступом
  «Только я», а сам аккаунт должен быть закрытым.
- **Выкладывать удобнее всего так:**
  1. В панели: Лента → «Выбрать» → «⬇ Скачать» — скачаются видео и обложки 9:16.
  2. TikTok Studio на компьютере (tiktok.com/tiktokstudio/upload) → загрузить сразу несколько
     роликов → «Запланировать» до 10 дней вперёд.
  3. Подпись взять из карточки ролика: «📋 Подпись».
  4. Включить «Контент, созданный ИИ».
- **Статистика работает в режиме Sandbox** — проверка TikTok для этого не нужна. В Sandbox
  подключаются до 10 своих аккаунтов (Target users).

## Подключение — один раз, ≈ 15 минут

1. **Аккаунт разработчика:** developers.tiktok.com → Log in (тем же TikTok, что у канала).
2. **Приложение:** Manage apps → Connect an app. Название — без слова «TikTok», например «Sut Panel».
   - Category: Entertainment / Education.
   - Terms of Service URL: `https://<адрес панели>/terms`.
   - Privacy Policy URL: `https://<адрес панели>/privacy`.

   Обе страницы открываются без пароля, TikTok упомянут в политике.
3. **Sandbox:** вверху страницы приложения переключатель Production / **Sandbox** → Create
   sandbox. Дальше всё делается в Sandbox.
4. **Продукт Login Kit:** Add products → Login Kit → платформа **Web**.
   - Redirect URI — ровно адрес со страницы «TikTok» в панели:
     `https://<адрес панели>/api/tiktok/callback`, без параметров и `/` в конце.
5. **Права (Scopes):** `user.info.basic`, `user.info.profile`, `user.info.stats`, `video.list`.
   Если `video.list` или `user.info.stats` в списке нет, добавьте продукт Display API.
6. **Target users** (в Sandbox): Add → ваш аккаунт TikTok. Только он сможет подключиться.
7. **Ключи в Vercel:** Settings → Environment Variables:
   - `TIKTOK_CLIENT_KEY` — Client key;
   - `TIKTOK_CLIENT_SECRET` — Client secret.

   Затем Deployments → ⋯ → Redeploy.
8. **Подключить:** панель → «Статистика» → «TikTok →» → «Подключить TikTok». Войдите в TikTok и
   нажмите «Разрешить». На iPhone вход откроется в отдельном окне: после надписи «TikTok
   подключён» закройте его и обновите панель.

## Как это устроено

- Вход — Login Kit (OAuth v2). В `state` — срок и подпись `SESSION_SECRET`, поэтому возврат
  `/api/tiktok/callback` работает и без cookie (окно входа на iPhone их не видит).
- Ключи TikTok лежат в переменной репозитория `PANEL_TIKTOK` в зашифрованном виде: AES-256-GCM,
  ключ шифрования выводится из `TIKTOK_CLIENT_SECRET`.
  - Без секрета из Vercel по ним ничего не сделать.
  - Ключ доступа живёт сутки, панель обновляет его сама; ключ обновления — год.
  - Новый `TIKTOK_CLIENT_SECRET` → «Подключить» заново.
- «Отключить» на странице «TikTok» отзывает доступ у TikTok и стирает переменную.
- Display API отдаёт только публичные ролики (до 100 последних). Обложки по ссылкам TikTok живут
  около 6 часов — страница берёт их заново при каждом открытии.
- Другие права можно задать переменной `TIKTOK_SCOPES` (через запятую), но они должны быть
  добавлены и в приложении.

## Ошибки

- **«redirect_uri»** при входе — в портале другой адрес. Скопируйте его со страницы «TikTok».
- **«scope»** — права не добавлены в приложение или при входе сняли галочки.
- **«доступ истёк или отозван»** — нажмите «Подключить TikTok» ещё раз.
- **TikTok не открывается** (в Кыргызстане он заблокирован с 2024 года) — подключайтесь через
  VPN. Сама панель работает на серверах Vercel, блокировка её не касается.

## Заработок в TikTok

Официальная монетизация TikTok — Creator Rewards. Условия:
- 18+, личный аккаунт;
- 10 000 подписчиков;
- 100 000 просмотров за 30 дней;
- оригинальные ролики **дольше 1 минуты**.

Программа работает только в США, Великобритании, Германии, Франции, Японии, Южной Корее, Бразилии
и Мексике. Кыргызстана, Казахстана и России среди них нет.

В России с марта 2022 года не показываются новые ролики. Поэтому TikTok для канала — скорее витрина:
ссылка на YouTube в профиле (монетизация там) и интеграции с брендами, когда вырастет аудитория.
Прогресс до порогов Creator Rewards виден на странице «TikTok».
