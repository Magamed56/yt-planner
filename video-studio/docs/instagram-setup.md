# Instagram: автоматическая публикация Reels

Ролики уходят в Instagram через **официальный API Meta**. Это бесплатно, без сторонних сервисов,
и пароль Instagram никому не передаётся. Настройка займёт 20–30 минут, её делают один раз на
компьютере.

Не хотите настраивать? Есть **ручной путь**: на каждый ролик уходит около минуты с телефона,
см. раздел «Без API: вручную» в конце.

## Что нужно знать заранее

- У Meta два варианта API для Instagram. Наш вариант — **«Instagram API with Facebook Login for
  Business»**. Только он умеет загрузить видео **прямо из файла**. Второму варианту («with
  Instagram Login») нужна публичная ссылка на видео в интернете, а у нас ролик лежит в папке
  или на сервере GitHub.
- Поэтому нужны **профессиональный аккаунт Instagram** и **страница Facebook**, связанные между
  собой. Страница нужна только для API: вести её не обязательно.
- **Отложенной публикации в API Instagram нет.** Публиковать «в 12:00 и 19:00» умеет наш
  отдельный workflow в GitHub: дважды в день он выкладывает следующий ролик из очереди.
- Лимит API — до 100 публикаций за скользящие 24 часа (в части документации Meta указано 50).
  Нам нужно 2 в день.

## Шаг 1. Профессиональный аккаунт и страница Facebook

1. **Instagram (приложение) → Профиль → ☰ (справа вверху) → «Настройки и действия» →
   «Тип аккаунта и инструменты» → «Переключиться на профессиональный аккаунт».** Категория:
   «Образование» или «Блогер». Тип: **«Бизнес»** (у Meta он надёжнее всего работает с API).
2. Страница Facebook: на компьютере откройте [facebook.com/pages/create](https://www.facebook.com/pages/create).
   Название: `Суть за минуту`, категория «Образовательный сайт». Нужен любой аккаунт Facebook.
3. Свяжите страницу и Instagram. **Instagram → «Редактировать профиль» → «Страница» →
   «Подключить существующую страницу»** и выберите `Суть за минуту`. Другой путь: на странице
   Facebook откройте «Настройки» → «Связанные аккаунты» → «Instagram» → «Подключить аккаунт».

## Шаг 2. Приложение Meta (для ключа)

1. Откройте [developers.facebook.com](https://developers.facebook.com) и войдите тем же аккаунтом
   Facebook. Если просит, согласитесь стать разработчиком: это бесплатно.
2. **«Мои приложения» → «Создать приложение».**
   - Название: например, `sut-publisher`.
   - Сценарий использования: **«Управление сообщениями и контентом в Instagram»**
     (Manage messaging & content on Instagram).
   - Если спросит про бизнес-портфолио, можно выбрать «Не связывать сейчас».
3. В приложении, в разделе Instagram, выберите вариант **«Настройка API с входом через Facebook»**
   (API setup with Facebook login).
4. Приложение остаётся в **режиме разработки**. Для своего аккаунта этого хватает: проверку
   приложения (App Review) проходить не нужно.
5. Запишите **ID приложения** и **секрет приложения**: **«Настройки приложения» → «Основное»**,
   у секрета нажмите «Показать». Это `IG_APP_ID` и `IG_APP_SECRET`. Они нужны только для
   продления токена на вашем компьютере, в GitHub их класть **не надо**.

## Шаг 3. Токен и IG_USER_ID

1. Откройте **Graph API Explorer**: [developers.facebook.com/tools/explorer](https://developers.facebook.com/tools/explorer).
2. Справа: «Приложение Meta» — ваше приложение; «Пользователь или страница» — **«Маркер
   пользователя»** (User Token).
3. В «Разрешениях» (Permissions) добавьте четыре:
   `instagram_basic`, `instagram_content_publish`, `pages_read_engagement`, `pages_show_list`.
   Если страница лежит в бизнес-портфолио Meta, добавьте ещё `business_management`.
4. **«Generate Access Token»**. В окне входа отметьте **и страницу `Суть за минуту`, и аккаунт
   Instagram**, затем подтвердите. Скопируйте токен: длинная строка, начинается с `EAA`. Этот
   токен живёт около часа, сейчас мы сделаем постоянный.
5. На компьютере, в папке `video-studio`, впишите в файл `.env`:
   ```
   IG_APP_ID=…
   IG_APP_SECRET=…
   ```
   и выполните (вставьте свой токен вместо `EAA…`):
   ```bash
   npm run instagram-token -- --token EAA… --exchange --page --save
   ```
   Программа:
   - обменяет токен на долгоживущий (около 60 дней);
   - найдёт ваш Instagram-аккаунт и напечатает **`IG_USER_ID`**: это число вида `17841400000000000`,
     а не `@ник`;
   - получит **токен страницы**. Он **не истекает**, пока вы не смените пароль Facebook, не
     отзовёте права приложения и не потеряете роль администратора страницы;
   - запишет `IG_USER_ID` и `IG_ACCESS_TOKEN` в `.env` (флаг `--save`).
6. Проверка в любой момент: `npm run instagram-token`. Покажет срок токена, его права и `IG_USER_ID`.

**Без компьютера.** В Graph API Explorer нажмите на значок «i» у токена → **«Open in Access Token
Tool»** → **«Extend Access Token»**: получится токен на 60 дней. `IG_USER_ID` можно узнать там же:
впишите в строку запроса `me/accounts?fields=name,instagram_business_account` и нажмите
«Submit». Число в `instagram_business_account.id` и есть `IG_USER_ID`.

## Шаг 4. Секреты GitHub

**Репозиторий на github.com → Settings → Secrets and variables → Actions → New repository secret:**

| Секрет | Что вписать |
|---|---|
| `IG_USER_ID` | число из шага 3, например `17841400000000000` |
| `IG_ACCESS_TOKEN` | токен из шага 3 (строка `EAA…`) |

`IG_APP_ID` и `IG_APP_SECRET` в GitHub класть не нужно.

Необязательные **Variables** (вкладка рядом): `IG_API_VERSION` (по умолчанию `v26.0`) и
`IG_AI_GENERATED` (по умолчанию `1`: у Reels ставится пометка «Создано с помощью ИИ», потому что
голос синтезирован; `0` убирает её).

## Шаг 5. Продление токена (если это не токен страницы)

- **Токен страницы** (`--page`) продлевать не нужно.
- **Токен пользователя** живёт около **60 дней**. Поставьте напоминание в календарь раз в
  50 дней и выполните `npm run instagram-token -- --exchange --save`. Новый токен вставьте в
  секрет `IG_ACCESS_TOKEN` на GitHub: Settings → Secrets → карандаш у `IG_ACCESS_TOKEN`.
- Если токен уже истёк, программа напишет «токен IG_ACCESS_TOKEN истёк». Повторите шаг 3.

## Как публикуются ролики

У каждого ролика в папке `out/<имя>/` (и в релизе GitHub) есть:

| Файл | Что это |
|---|---|
| `video.mp4` | сам ролик 1080×1920. Перед отправкой звук сам перекодируется под требования Reels |
| `instagram.txt` | подпись: цепляющая первая строка, суть, призыв к комментарию и подписке, до 5 хэштегов (лимит Instagram). **Можно править**: уйдёт именно этот текст. Ссылок в подписи нет, в Instagram они не кликаются |
| `cover.jpg` | обложка 1080×1920: кадр конца первой сцены без субтитров |
| `instagram.json` | служебный файл: кадр обложки (`thumbOffsetMs`) |

API ставит обложкой тот же кадр, что в `cover.jpg`. Сам файл обложки API принимает только по
публичной ссылке, поэтому `cover.jpg` нужен для ручной публикации.

### Сразу, с компьютера

```bash
npm run upload -- out/<папка ролика> --to instagram
npm run make -- --script scripts/x.json --upload youtube,instagram --schedule   # YouTube в слот, Instagram сразу
```

Повторно тот же ролик не уйдёт: появится сообщение «уже опубликован». Если нужно ещё раз, добавьте
`--force`. Кроме того, перед публикацией программа сверяет подпись с последними постами
аккаунта. Если прошлый запуск оборвался уже после публикации, дубля не будет.

### По расписанию, через GitHub (12:00 и 19:00)

1. Соберите пакет: **Actions → «video-studio: ролик» → Run workflow** → `mode = batch`,
   `script = video-studio/scripts/sut-01*.json`, `upload = release+youtube+instagram`,
   `schedule = slots`. Каждый ролик попадёт в **релиз GitHub** с файлом `instagram.json`.
   Такие релизы и есть очередь Instagram. YouTube получит их по слотам сам.
2. Workflow **«video-studio: Instagram по расписанию»** при каждом запуске публикует **самый
   старый** ролик из очереди и добавляет в его релиз файл `instagram-published.json`.
   - Запустить вручную: **Actions → «video-studio: Instagram по расписанию» → Run workflow**.
     Флажок `dry_run` только покажет, что будет опубликовано.
   - **Включить расписание**: в файле `.github/workflows/video-studio-instagram.yml` уберите `#`
     перед строками `schedule:` и двумя `- cron:` и сохраните (Commit changes). После этого он
     запускается в 12:04 и 19:04 по Москве. Если GitHub перегружен, запуск может задержаться на
     5–20 минут. Расписание работает, только когда файл лежит в ветке по умолчанию (`main`).
3. Очередь кончилась — workflow просто напишет «Очередь пуста». Наполните её следующим пакетом.

Убрать ролик из очереди: удалите из его релиза файл `instagram.json`. Опубликовать вне очереди:
в поле `tag` при ручном запуске укажите тег релиза.

## Без API: вручную (около минуты на ролик)

1. Скачайте на телефон из релиза GitHub (или из папки `out/<имя>/`) файлы `video.mp4`,
   `cover.jpg` и `instagram.txt`. Удобно переслать их себе в Telegram «Избранное» **как файлы**,
   а не как фото, чтобы не потерялось качество.
2. Instagram → **«+» → «Reels»** → выберите `video.mp4` → **«Далее»**.
3. **«Изменить обложку» → «Добавить из галереи» → `cover.jpg`**.
4. Вставьте текст из `instagram.txt`.
5. Отметка ИИ: **«Расширенные настройки» → «Добавить метку ИИ»** (голос синтезирован).
6. Опубликовать в нужное время: **«Расширенные настройки» → «Запланировать публикацию»** → дата
   и время → «Поделиться». Instagram опубликует ролик сам. Так можно заранее запланировать всю
   неделю.

На компьютере удобнее **Meta Business Suite** ([business.facebook.com](https://business.facebook.com)):
**«Планировщик» → «Создать» → «Reels»**. Там можно расставить по времени сразу много роликов.

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| `токен IG_ACCESS_TOKEN истёк` / `недействителен` | Повторите шаг 3 и обновите секрет `IG_ACCESS_TOKEN` |
| `у токена нет нужного разрешения` | В шаге 3 не хватило галочки: выпустите токен заново со всеми четырьмя разрешениями и отметьте в окне входа и страницу, и Instagram |
| `IG_USER_ID … должен быть числовой id` / `объект не найден` | В `IG_USER_ID` вписан ник или id страницы. Узнайте правильный: `npm run instagram-token` |
| `начинается с «IG»` | Это токен второго варианта API («Instagram Login»). Нужен токен `EAA…` из шага 3 |
| `видео не подходит для Reels` | Нужен MP4 H.264 + AAC, от 3 секунд до 15 минут, до 300 МБ. Наши ролики подходят. Если ролик правили вручную, пересоберите его через `npm run make` |
| `лимит публикаций через API` | Подождите сутки. Обычно это значит, что публикации шли ещё откуда-то |
| `Instagram временно ограничил действия` | Meta заподозрила спам: подождите сутки и проверьте уведомления в приложении. Публикуйте не чаще 2–3 раз в день |
| `Ни одна страница … не связана` | Шаг 1: аккаунт не профессиональный или страница не привязана |
| Workflow: «Очередь Instagram пуста» | Нет релизов с `instagram.json`: соберите пакет с `upload`, в котором есть `instagram` |
