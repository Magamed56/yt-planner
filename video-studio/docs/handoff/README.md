Владелец выкладывает по одному новому ролику в день. Через 72 часа после выхода сравниваем просмотры с прежним
уровнем (≈ 1100, максимум 1900). Хоть один ролик набрал от 3000 — формат и темы работают, продолжаем по ролику в
день. Все легли в ту же тысячу — канал закрываем и больше не тратим ни времени, ни денег.

## Ограничения, о которые уже спотыкались
- Cloudflare (кадры): бесплатной дневной квоты хватает примерно на 3 Shorts в кинорежиме в сутки (сброс в 00:00
  UTC). Четвёртый ролик останется без кадров. «Разбор» съедает квоту целиком.
- Claude API: месячный лимит расходов. 25.10 он кончился посреди сборки — ролики собрались без проверки кадров.
  Сценарий Shorts в кинорежиме ≈ $0,5–0,65, проверка кадров ≈ $0,15.
- Сборки 33c, 34a, 34b от 25.10 — брак (кадры запасного генератора, без проверки кадров): не публиковать,
  пересобрать. Черновые релизы 32c, 33a, 33b от 24.10 — нормальные.
- Готовы, но не выложены: Shorts 28b–30b (старый формат), «Разборы» L13–L16.
- Лимит веб-поиска в облачной сессии — 200 запросов на ход, общий для всех помощников: при проверке 25 тем он
  кончился, остаток сверяли по Википедии (в среде `yt-planner` разрешены `www.youtube.com`, `en.wikipedia.org`,
  `ru.wikipedia.org`, `wikimedia.org`).

- Автозагрузка на YouTube по-прежнему невозможна: проект Google не прошёл аудит API, и YouTube запирает такие
  загрузки приватными. Текст заявки — `docs/youtube-audit.md`, отправляет владелец; после одобрения — `upload` с
  `youtube` и `schedule = slots`. До тех пор владелец загружает файл в Studio, тексты и время ставит панель.
- В `channel.json` всё ещё три слота Shorts в день и «Разбор» в 20:00. Для теста «один ролик в день» расписание
  не менялось — это решение владельца.
