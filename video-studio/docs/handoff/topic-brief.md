# Бриф: тема «Разбора» для content/long-plan.json — факты с источниками

Канал «Суть за минуту» (русскоязычный научпоп, 14–45 лет, «Сложное — просто»). «Разбор» — ролик 16:9 ~7 минут,
рассказ-детектив: загадка → попытки → тупики → поворот → развязка. Темы выбраны владельцем канала через меня;
твоя задача — собрать для КАЖДОЙ своей темы проверенный фундамент, по которому потом напишут сценарий.

Репозиторий: video-studio. Ничего в нём не меняй, не коммить. Пиши только свой JSON-файл в docs/handoff/.
Посмотри формат: `content/long-plan.json` (элементы L02–L06 — образец полей и тона).

## Что нужно на каждую тему
JSON-объект:
```
{
  "id": "L07", "day": 7, "slot": "20:00", "pillar": "<id рубрики>",
  "title": "<рабочее название темы по-русски, до 70 символов, с поисковым запросом>",
  "hook": "<хук ≤ 12 слов: конкретный, неожиданный, проверяемый>",
  "angle": "<3–4 предложения: сюжет-детектив, повороты и развязка, самый сильный факт — ближе к концу>",
  "keyFacts": [ { "claim": "<одно проверенное утверждение по-русски, с цифрами/датами/именами>", "source": "<URL первоисточника>" }, … 10–12 штук ],
  "chapters": [ "<5–6 глав по 2–5 слов>" ],
  "status": "planned"
}
```
- keyFacts: 10–12 фактов, у КАЖДОГО — URL источника (минимум 8 разных живых страниц на тему). Предпочитай
  первоисточники: научные статьи (doi.org, PubMed, Nature, Science, PNAS…), NASA/ESA, nobelprize.org, музеи,
  Britannica, университеты, крупные СМИ с цитатами учёных. Wikipedia — только если нет лучшего.
- Каждое число, дату и имя проверь поиском (WebSearch; WebFetch может не работать — опирайся на выдачу).
  Не уверен — не включай. Мифы — только как разоблачение. Спорное помечай как спорное в claim.
- Цитаты — только задокументированные; иначе пересказ.
- Нельзя: политика, войны (и военные подробности), религиозные споры, медицинские или финансовые советы.
- В angle — честная развязка (что зритель поймёт иначе), без кликбейта, который ролик не оправдает.

## Результат
Запиши массив объектов своих тем в `docs/handoff/topics-<твои коды>.json`
(валидный JSON, UTF-8), проверь `python3 -c "import json;json.load(open('<файл>'))"`.
В финальном ответе — по каждой теме: title, hook, 1 строка angle, сколько фактов и что оказалось мифом/спорным
по ходу проверки (если что-то из моей формулировки темы неверно — скажи прямо и предложи правку).
