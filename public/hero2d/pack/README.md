# Mansurov N.N. — 2D-персонаж

## Видео (`video/`)
- `*-green.mp4`: 1080×1920, зелёный фон, ~8 секунд по кругу. В CapCut: «Наложение» → «Удалить фон» → «Хромакей».
- `*-alpha.webm`: то же с прозрачным фоном, для OBS, сайтов и редакторов, которые понимают альфа-канал.
- Анимации: `idle` стоит, `talk` говорит, `wave` машет, `walk` идёт на месте, `think` думает.

## Игры (`sprites/`)
- PNG-листы на прозрачном фоне, кадр 372×640, 12,5 кадра в секунду.
- Размеры сетки и число кадров — в `sprites.json`. Подходят для Unity (Sprite Editor → Grid by Cell Size), Godot (AnimatedSprite2D) и Construct.

## Spine 2D / Live2D (`spine/`)
- `parts/`: части тела отдельными PNG на одном холсте 1200×2000.
- `rig.json`: где лежит каждая часть (`x`, `y` = левый верхний угол на холсте), точки вращения суставов (`pivot`), порядок слоёв и наборы для замены:
  - лица: `face_*` — 6 эмоций и моргание;
  - рты: `mouth_*` — эмоции и формы для речи A, E, O, M;
  - кисти: обычная и раскрытая ладонь.
- Расставьте части по координатам из `rig.json`, создайте кости в точках `pivot` и привяжите каждую часть к своей кости.
