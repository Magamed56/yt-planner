# Mansurov N.N. — 2D-персонаж по вашему рисунку

Персонаж вырезан из вашей картинки и собран на скелет. Лица взяты из листа с 8 эмоциями.

## Видео (`video/`)
- `*-green.mp4`: 1080×1920, зелёный фон, ~8 секунд по кругу. В CapCut: «Наложение» → «Удалить фон» → «Хромакей».
- `*-alpha.webm`: то же с прозрачным фоном, для OBS, сайтов и редакторов с альфа-каналом.
- Анимации: `idle` стоит, `talk` говорит, `wave` машет, `walk` идёт на месте, `present` показывает рукой в сторону.

## Игры (`sprites/`)
- PNG-листы на прозрачном фоне, 12,5 кадра в секунду. Размер кадра, число кадров и сетка — в `sprites.json`.
- Unity: Sprite Editor → Slice → Grid by Cell Size. Godot: AnimatedSprite2D → «Добавить кадры из спрайт-листа».

## Spine 2D (`spine/`)
- `parts/`: 14 частей тела и 20 слоёв головы на общем холсте 848×1264.
- `rig.json`: где лежит каждая картинка (`x`, `y`), суставы (`pivot`), какая кость главная (`parent`), порядок слоёв.
- Голова: 8 эмоций (`head_<эмоция>.png`), у каждой есть вариант с закрытыми глазами (`_blink`).
- Речь: `head_mouth_A/E/O/rest.png` кладутся поверх головы, чтобы рот двигался.
- Голова стоит за воротником: в порядке слоёв она идёт перед туловищем.

## Остальное
- `emocii.png`: все 8 эмоций на одном листе.
- `gif/`: короткие превью анимаций.
